# NOP Studio

**NOP Studio** is a macOS application for designing and experimenting with custom 8-bit CPUs.

It provides an integrated environment for writing assembly code, assembling programs, simulating CPU execution, and disassembling machine code.

### Features
- Assembly code editor
- Two-pass assembler with label resolution
- Customizable CPU instruction sets using JSON
- 8-bit CPU emulator with step-by-step execution
- Register and memory inspection
- Machine code disassembler
- Binary, HEX, and Logisim output

NOP Studio is designed for learning, experimenting with, and developing custom CPU architectures.

### Requirements
- macOS 14.0 or later
